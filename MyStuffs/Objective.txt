Stage_01 — Basic Application Skeleton + User Authentication

Objective:
Have a minimal frontend that communicates with Spring Boot,
allowing a user to authenticate against user data stored in PostgreSQL.

1. Frontend
   - [X] Basic index page
   - [X] Basic login/authentication page
   - [X] Basic CSS/layout
   - [X] Basic JavaScript for making requests to the backend
   - [ ] Display authentication result / basic user information

2. Backend
   - [X] Basic GET request handling with controllers
   - [X] Basic POST request handling
   - [ ] Basic authentication logic
   - [ ] PostgreSQL connection
   - [ ] Repository for accessing user data
   - [ ] Appropriate HTTP responses for success/failure

3. Database
   - [ ] Users table / relevant user entity
   - [ ] User identifier
   - [ ] Username/email
   - [ ] Password representation
   - [ ] Basic queries for retrieving users
   - [ ] Seed/test users

4. Integration
   - [ ] Browser can request the index page
   - [ ] Browser can open the login page
   - [ ] Login form sends credentials to Spring Boot
   - [ ] Spring Boot queries PostgreSQL
   - [ ] Backend returns authentication result
   - [ ] Frontend reacts to the result
